# Agent instructions

- Keep this repository independent from Wellfound and other GrowthTech systems.
- Never copy or commit API keys, browser profiles, application reports or personal profile data.
- Reuse the existing application motor; do not create parallel scripts for the same flow.
- Use structured logging instead of `print()`.
- Run Python with `.venv\Scripts\python.exe -X utf8`.
- Run compilation, tests, self-check and `git diff --check` after code changes.
- Do not submit a real application unless the human explicitly authorizes the batch and quantity.
- Do not commit or push without explicit authorization.
